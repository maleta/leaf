# Old spec (superseded)

Kept for the record. The `.markdown` extension is here on purpose: the app
opens `md`, `markdown`, `mdown`, `mkd`, `mdx` and `txt`.

## Original scope

A viewer. No editor, no tree, no settings.

## What changed

- The editor arrived because reading and fixing a typo are the same session.
- The tree arrived because nobody opens exactly one file.
- Settings arrived because the typewriter needed a speed.

Each of those was a "we will never need this" at some point.
