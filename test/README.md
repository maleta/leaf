# Demo folder

Material for screenshots and the demo GIF. Open `00-welcome.md` and press `⌘B`.

| File | Shows |
| --- | --- |
| `00-welcome.md` | the hero shot: code, math, a diagram, a table, all in one screen |
| `01-code.md` | shiki across eight languages |
| `02-math.md` | KaTeX inline, display, matrices, math inside a table |
| `03-diagrams.md` | mermaid flowchart, sequence, state, gantt, pie, class |
| `04-kitchen-sink.md` | every ordinary Markdown construct, plus a missing-image fallback |
| `05-long-read.md` | long enough to scroll: the scroll-memory demo |
| `06-typewriter.md` | short on purpose: the typewriter replay demo |
| `notes/`, `spec/` | nested folders, and the `.markdown` / `.mdx` / `.txt` extensions |
| `assets/` | files the app lists but will not open, greyed out |

## Recording script

1. **Finder** - double-click `00-welcome.md`. The window opens already rendered.
2. **Scroll** slowly through it: code block, math, mermaid, table.
3. `⌘B` - the tree slides in. Folders first, then openable files with their
   sizes, then `assets/` greyed out.
4. Single-click `03-diagrams.md`, then `02-math.md`. Instant, every time.
5. Double-click `notes/`, open `meeting-notes.md`, use the parent button to
   come back out.
6. Open `05-long-read.md`, scroll halfway down, switch to another file, switch
   back. It returns to where you were.
7. `⌘E` - split editor. Type a heading in the left pane; the preview follows.
8. `⌘,` - settings. Switch **Rendering** to *Typewriter*, close settings.
9. Open `06-typewriter.md` and let it type. Press ▷ to replay.
10. Settings again - flip the theme to dark. End on the dark hero shot.

Roughly 40 seconds at a calm pace.
